# 血統與繁殖系統

## 繁殖系統
可將退役馬轉型成為繁殖馬進行繁育。

### 繁殖規則
- 馬匹3~12歲可以繁殖
- 在每年4~6月進入配種期，若已受孕則進入產駒期。
- 可透過自然交配(速度慢，受孕率高，成本低)或人工授精(速度快，擴大優良基因的使用範圍，成本高)進行繁殖
- 種馬規則:
    * 需要規律、平靜的日常作息以保持健康快樂。
    * 一年可無限制進行繁殖，但過度繁殖會影響精液品質或使馬匹疲勞。
    * 繁殖期間馬匹可能變得大膽或具有攻擊性。
- 繁殖母馬規則: 
    * 產駒期約11個月。
    * 發情週期: 持續21至22天，其中發情期活躍6至8天。
    * 一年最多可以進行4次配種嘗試。
    * 請獸醫安排配種前健康檢查。
    * 繁殖期間須維持母馬健康強壯的體重，以確保最佳繁殖力。
    * 配種後約14至16天進行獸醫檢查。
    * 產駒期結束時若仍在配種期則該配種期不進行配種。
- 存在繁殖失敗可能。
- 種馬不占用育馬場容量，但繁殖母馬會占用育馬場容量。

### 種馬費
由種馬血統 + 比賽成績決定。
