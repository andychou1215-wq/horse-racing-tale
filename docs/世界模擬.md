# 世界模擬

## 核心迴圈
- 現役馬退役 → 部分進入繁殖 → 產生下一代 → 幼駒進入NPC/市場 → 新馬參賽 → 形成新的明星馬
- 新人騎師出道 → 成長(出道5~10年) → 巔峰(出道10~20年) → 衰退(出道20~25年) → 退役(出道25+年)

## 馬匹人口循環
出生 → 幼駒 → 現役 → 退役(繁殖/展示/養老/離開模擬世界/死亡)

## 馬匹人口數字
- 現役賽馬上限: 3000~5000匹
- 繁殖馬上限: 1000~2000匹
- 展示 + 養老馬上限: 1000~2000匹
- 每年進入退役馬: 最多500~1000匹
- 每年幼駒數: 最多500~1000匹
- 每年幼馬數: 最多500~1000匹
- 幼駒進入NPC/市場比例: 7:3
