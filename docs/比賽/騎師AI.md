# 騎師AI

## 騎師能力
- 起跑判斷
- 位置判斷
- 節奏控制
- 路線選擇
- 終盤判斷
- 精神穩定
- 戰術執行

## 騎師市場配對邏輯
- 當多匹馬的騎乘邀約發生衝突時，由自由騎師自行評估並選擇邀約。
- 在比賽前一週的邀約競爭階段，不採先到先得或單次邀約，而是進行多輪配對(固定進行3輪)。
- 每匹馬每輪提交有限數量的自由騎師志願順位。
- 每一輪騎師配對結束後，只要馬匹與騎師成功配對，該次騎乘安排立即成立。
- 三輪配對後進入最後時刻騎師市場，仍無法取得騎師才強制退賽。
    - 最後時刻騎師市場只顯示已預先願意接受騎乘的騎師，採隨機選秀順位。
    - 最後時刻騎師市場選秀中可以放棄選擇騎師並主動退賽。
