# 比賽公式
基礎能力分數 × 跑法階段倍率 × 騎師修正 × 距離適性 × 場地適性 × 狀態倍率 × 負磅修正 × 特性 × 戰術波動 × 隨機波動

修正紀錄: 原本「跑法適配度」同時出現在前段/中段的基礎分數公式裡、又以「跑法階段倍率」列在外部乘數，等於同一個效果被算了兩次。
現在統一改成只在外部乘數層套用一次——跑法階段倍率＝馬匹/馬匹系統.md「跑法適配度」表格的數值，六個階段(含彎道，恆為1.00)都會套用，
不再寫進任何一個階段的基礎分數公式裡。

## 起跑基礎階段表現分數
加速 * 0.3 + 起跑 * 0.5 + 精神 * 0.2

## 前段基礎階段表現分數
速度 * 0.65 + 騎師適配度 * 0.35

## 中段基礎階段表現分數
速度 * 0.3 + 耐力 * 0.3 + 騎師適配度 * 0.4

## 後段基礎階段表現分數
耐力 * 0.5 + 根性 * 0.2 + 剩餘體力 * 0.3

## 彎道基礎階段表現分數
力量 * 0.2 + 智力 * 0.4 + 彎道 * 0.4

## 衝刺基礎階段表現分數
速度 * 0.4 + 加速 * 0.4 + 根性 * 0.2

## 狀態倍率
S(1.2) → A(1.1) → B(1.0) → C(0.9) → D(0.8)
- 由當下馬匹的「狀態(賽前分級)」決定，詳見 馬匹/狀態與健康.md「狀態(賽前分級)」；與健康屬性的「傷病風險分級」是各自獨立的呈現。

## 負磅修正
以基準數為主，每±1公斤表現修正-1%

## 特性
- 每個觸發中的特性對所屬階段表現造成 ±5%~±8% 修正(正面特性為加成、負面特性為懲罰)。
- 詳見 馬匹/馬匹系統.md「特性」章節。

## 戰術波動
- 戰術波動 = 戰術基礎效果 × 戰術執行修正
- 戰術基礎效果: 依戰術系統.md 各戰術的優點/代價換算，分成三個風險等級：
    * 保守型(保存體力、自由發揮): 波動範圍較小 ±3%~±5%
    * 中風險型(跟隨領先馬、外側超車、內側突破): 波動範圍中等 ±6%~±10%
    * 高風險型(積極搶位、提早加速、後發制人): 波動範圍較大 ±8%~±15%
- 戰術執行修正 = (馬匹「戰術」屬性 × 0.5 + 騎師「戰術執行」能力 × 0.5) 轉換的穩定係數，範圍 0.9~1.1；執行修正越高，優點發揮機率越高、風險觸發機率越低。

## 騎師適配度
- 由 比賽/騎師AI.md 所列的騎師能力組合而成，反映該騎師在特定階段的臨場調度品質(與整體「騎師修正」不同，後者代表騎師的總體等級)。
- 前段: 位置判斷 * 0.6 + 節奏控制 * 0.4
- 中段: 節奏控制 * 0.5 + 路線選擇 * 0.5

## 騎師修正
- 修正說明: 騎師AI.md 定義的7項騎師能力中，位置判斷/節奏控制/路線選擇已用於「騎師適配度」影響前段/中段，戰術執行已用於「戰術執行修正」；起跑判斷、終盤判斷、精神穩定三項原本沒有任何公式使用，現統一併入「騎師修正」，讓7項能力都對比賽有實際影響。
- 騎師修正 = (起跑判斷 + 位置判斷 + 節奏控制 + 路線選擇 + 終盤判斷 + 精神穩定 + 戰術執行) ÷ 7，轉換為 0.9~1.1 的穩定倍率。
- 代表騎師的總體等級，套用在全部六個階段的最終表現分數上(與只影響特定階段的「騎師適配度」不同，兩者可以同時存在、不重複)。

## 隨機波動
波動範圍: ±5%~±10%
