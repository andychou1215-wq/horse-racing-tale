# 體力系統

## 體力
單場比賽中的動態資源，耐力決定體力消耗速度。

## 基準體力曲線
- 起跑：100%
- 前段：88%
- 中段：64%
- 後段：37%
- 衝刺：12%

## 階段體力消耗
基礎消耗 × 距離修正 × 耐力修正 × 跑法修正 × 戰術修正 × 場地修正
* 耐力修正：0.8～1.2
* 距離修正：0.8～1.3
* 跑法修正(依階段而異，反映跑法的體力分配節奏):
    * 逃: 起跑1.15 / 前段1.20 / 中段1.00 / 後段0.90 / 衝刺0.85
    * 先: 起跑1.00 / 前段1.05 / 中段1.05 / 後段1.00 / 衝刺0.95
    * 差: 起跑0.95 / 前段0.95 / 中段1.00 / 後段1.05 / 衝刺1.05
    * 追: 起跑0.90 / 前段0.90 / 中段0.95 / 後段1.05 / 衝刺1.15
* 戰術修正：0.9～1.2
* 場地修正：1.0～1.2

## 特殊消耗規則
- 高耐力 → 每階段體力消耗較低
- 積極搶位戰術 → 前段額外消耗
- 外側超車戰術 → 額外消耗
- 沉重場地 → 額外消耗
- 距離過長 → 額外消耗
