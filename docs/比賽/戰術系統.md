# 戰術系統

## 規則
- 戰術皆由賽前指定。
- 一匹馬只能設定一種戰術。

## 戰術種類
- 積極搶位
    * 優點：提高前段位置競爭能力
    * 代價：增加前段體力消耗
    * 適合：逃、先
    * 風險：多匹馬同時搶位時容易造成過度消耗
- 保存體力
    * 優點：保存中後段耐力
    * 代價：前段速度減慢
    * 適合：差、追
    * 風險：短距離、一哩賽事可能無法發揮作用
- 跟隨領先馬
    * 優點：領先馬拉開後面隊伍差距時不會落隊
    * 代價：前中段體力消耗加快
    * 適合：逃
    * 風險：後段及最後衝刺時容易造成過度消耗
- 外側超車
    * 優點：避免阻塞於馬群中
    * 代價：消耗額外耐力
    * 適合：先、耐力值高
    * 風險：耐力值不夠時無法維持後段表現
- 內側突破
    * 優點：利用力量於馬群中開闢一條路，可節省耐力消耗
    * 代價：消耗額外體力值
    * 適合：差、力量值高
    * 風險：力量值不夠時可能無法突破而白白消耗體力值
- 提早加速
    * 優點：掌握先手時機
    * 代價：降低後續加速表現
    * 適合：逃、加速值高
    * 風險：過早加速可能導致最後衝刺時失速
- 後發制人
    * 優點：在其他馬匹加速完成後才加速，有望在最後翻盤
    * 代價：增加終盤負荷
    * 適合：追、根性值高
    * 風險：過晚加速可能導致追不到領先馬
- 自由發揮
    * 優點：無
    * 代價：無
    * 適合：所有
    * 風險：自由發揮可能導致馬匹表現不穩定
