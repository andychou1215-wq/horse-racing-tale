# 比賽模擬

## 賽馬場
- 每座賽馬場有固定賽道特性與賽道佈局。
- 賽道特性:
    * 直線長度(實際公尺數+分類)
    * 坡度/高低差特性(主要坡度特性)
    * 彎道特性(彎道數量+主要彎道特性)

## 比賽場地
草地/泥地/人工場地

## 比賽距離
- 實際距離(m)
- 距離分類(短距離/一哩/中距離/長距離)

## 賽道方向
左回/右回/直道

## 場地狀況
- 堅硬/良好/柔軟/沉重
- 天氣會影響場地狀況，但不直接一對一決定。
- 玩家在提前兩週報名時，不會知道最終場地狀況，而是取得天氣預報+預期場地狀況。

## 天氣系統
- 每個賽馬場都有自己的天氣狀態與天氣預報。
- 一年分成春夏秋冬四個季節。
- 天氣預報會顯示實際氣溫，但不直接參與馬匹能力、體力或比賽結果計算。

## 起跑檔位
- 正式參賽名單確定後，系統會為所有正式參賽馬匹隨機抽取起跑檔位。
- 比賽前一週進行起跑檔位抽籤。
- 有馬匹退賽且沒有候補馬遞補時，起跑檔位保留空缺。
- 修正說明: 起跑檔位抽籤與 比賽/騎師AI.md 的騎師3輪配對都在賽前一週進行，原本沒定義先後順序，現定案為「先抽檔位、後配對」——檔位抽籤在3輪配對開始前完成，讓自由騎師與馬主在志願排序時可以將起跑檔位納入考量(例如外側檔位配合外側超車戰術)。

## 比賽階段
- 起跑 → 前段 → 中段 → 後段 → 最後彎道 → 最後衝刺 → 終點
- 每個階段影響因素不同
- 採「階段式排名模擬」
    * 起跑 → 計算所有馬匹起跑表現 → 決定初始位置 → 前段 → 計算前段表現 → 更新馬匹位置 → 中段 → 計算中段表現 → 更新馬匹位置 → 後段 →計算後段表現 → 更新馬匹位置 → 最後彎道 → 計算彎道表現 → 更新馬匹位置 → 最後衝刺 → 計算衝刺表現 → 更新馬匹位置 → 終點 → 結算馬匹位置
- 位置值:
    * 「本馬階段表現」已經是套用完 比賽/比賽公式.md 全部修正項(跑法、騎師、距離/場地適性、狀態、負磅、特性、
      戰術波動、隨機波動)後的最終分數，位置值計算不需要再另外疊加戰術修正或騎師AI修正，避免重複計算。
    * 相對階段表現 = (本馬階段表現 - 全場平均階段表現) ÷ 全場平均階段表現
    * 修正說明(強者恆強問題): 原本用「新位置值＝舊位置值×(1+相對階段表現)」逐階段複利連乘，就算單一階段
      只小贏 10%~15%，六階段乘下來也會被放大成好幾倍的最終差距，導致比賽幾乎沒有黑馬翻盤空間。已改為
      「六階段加總平均」，不再複利：
    * 位置值(第N階段為止) = AVERAGE(相對階段表現_起跑 ~ 相對階段表現_第N階段)
      (逐階段更新的是「目前為止的平均相對表現」，用於呈現比賽過程中的即時排名，六個階段權重相同)
    * 終點名次依據 = 位置值(衝刺階段為止) = 六個階段相對表現的平均值，數值越大名次越前面。
