# 馬匹成長
- 馬匹1歲可以開始訓練，2歲可以參加新馬賽
- 馬匹年齡成長類型
    - 早熟
        * 2歲: 上升期
        * 3歲: 巔峰期
        * 4歲: 停滯期
        * 5歲: 衰退期(建議引退)
    - 一般
        * 2~3歲: 上升期
        * 4歲: 巔峰期
        * 5歲: 停滯期
        * 6歲: 衰退期(建議引退)
    - 晚成
        * 2~4歲: 上升期
        * 5歲: 巔峰期
        * 6歲: 停滯期
        * 7歲: 衰退期(建議引退)
    - 持久型
        * 2~3歲: 上升期
        * 4~5歲: 巔峰期
        * 6~7歲: 停滯期
        * 8歲: 衰退期(建議引退)
- 大部分能力會隨著年齡增長退化，除了智力與精神屬性。
- 若馬匹比賽表現不如預期或本身不適合比賽，可將其直接退役。

## 年齡成長倍率
- 修正說明: 培育系統.md 訓練公式裡的「年齡成長倍率」原本沒有對應數值，現補上各階段倍率。
- 上升期: 1.15(成長最快的階段)
- 巔峰期: 1.00(成長已趨緩，實際成長量主要由「潛力餘裕」控制)
- 停滯期: 0.6(訓練效益明顯下降)
- 衰退期: 0.3(訓練仍可小幅提升能力，但同時疊加下方的「衰退速率」)

## 衰退速率
- 除智力、精神外，其餘9項屬性(速度/耐力/加速/力量/根性/起跑/彎道/戰術/健康)進入衰退期後，每週固定衰退基礎值的0.3%~0.5%，具體衰退率依馬匹個體差異(如根性、健康)浮動。
- 可透過設施(恢復中心)、獸醫照護、降低比賽/訓練強度來減緩衰退速度，但無法完全消除。
