# 潛力與評估

## 潛力值
- 潛力值代表馬匹的上限程度
- 真正能力的潛力值使用數值(0~100)，玩家能看見的潛力職則使用S → A → B → C → D並採資訊不完全機制
    - 未鑑定幼駒:
        * 速度潛力：???
        * 耐力潛力：???
        * 整體潛力：B～S
    - 經過訓練: 整體潛力：A～S
    - 專業評估:
        * 速度潛力：S
        * 耐力潛力：B～A
        * 整體潛力：A+
- 潛力值越高的馬匹其能力上限也就越高，反之亦然。
- 由訓練師負責評估潛力，評估結果影響玩家與AI的訓練資源分配及交易決策，但不直接改變馬匹實際成長能力。

## 潛力顆粒度
- 定案: 每匹馬只有單一一個「整體潛力」數值(0~100)，不會為11項屬性(速度/耐力/加速/力量/根性/智力/起跑/彎道/戰術/精神/健康)各自建立獨立的潛力上限。
- 培育系統.md 訓練公式裡的「潛力餘裕=(潛力上限-該屬性目前值)÷100」，其中的「潛力上限」統一代入這個整體潛力值，11項屬性共用同一個上限，成長趨緩幅度一致。
- 「速度潛力」「耐力潛力」等單項潛力的S~D，是訓練師依該匹馬在特定面向(速度/耐力等)已展現的數值與整體潛力上限的差距，換算出的觀察值，用來讓資訊不完全的鑑定結果更有畫面感，並不是另外獨立存在的上限，實際訓練成長全部仍以同一個整體潛力上限計算。
