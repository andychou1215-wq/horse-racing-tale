# 馬匹系統

## 馬匹種類
- 幼駒: 剛出生的馬匹
- 幼馬: 可進行訓練，但不能出賽的馬匹
- 賽馬: 可比賽的馬匹
- 退役馬: 不比賽的馬
    * 繁殖馬: 專門繁殖子代的馬
    * 展示馬: 展示給參觀馬場的遊客的馬
    * 養老馬: 過退休生活的馬

## 詳細屬性
- 速度: 最高速度、衝刺能力
- 耐力: 長距離維持能力
- 加速: 從低速提升到高速的能力
- 力量: 爬坡、對抗、突破馬群
- 根性: 終盤、低體力時的表現
- 智力: 路線選擇、特性發動穩定度
- 起跑: 起跑能力
- 彎道: 彎道能力
- 戰術: 戰術執行穩定度，決定戰術優點發揮程度與風險觸發機率高低
- 精神: 緊張、壓力、比賽穩定度
- 健康: 疲勞與受傷風險

## 距離/場地適性
- 距離適性: 短距離/一哩/中距離/長距離
- 場地適性: 草地/泥地/人工場地/乾燥/濕地/重馬場
- 採S / A / B / C / D制呈現
    * S → 明顯比賽加成
    * A → 小幅比賽加成
    * B → 標準
    * C → 小幅比賽懲罰
    * D → 明顯比賽懲罰

## 跑法
- 逃：前期搶領先
    -  跑法適配度(以外部乘數「跑法階段倍率」套用在各階段的最終表現分數上，詳見 比賽/比賽公式.md):
        * 起跑: 1.10
        * 前段: 1.15
        * 中段: 1.00
        * 後段: 0.90
        * 彎道: 1.00
        * 衝刺: 0.85
- 先：保持前段位置
    -  跑法適配度:
        * 起跑: 0.90
        * 前段: 1.05
        * 中段: 1.10
        * 後段: 1.00
        * 彎道: 1.00
        * 衝刺: 0.90
- 差：中後段追趕
    -  跑法適配度:
        * 起跑: 0.90
        * 前段: 1.00
        * 中段: 1.10
        * 後段: 1.05
        * 彎道: 1.00
        * 衝刺: 0.90
- 追：最後階段爆發
    -  跑法適配度:
        * 起跑: 0.85
        * 前段: 0.90
        * 中段: 1.00
        * 後段: 1.10
        * 彎道: 1.00
        * 衝刺: 1.15
    - 彎道階段不受跑法影響(統一為1.00)，因為過彎表現由力量/智力/彎道屬性決定，跟前中後段的節奏策略無關。
- 可以配合戰術使用(詳見 比賽/戰術系統.md)

## 個性
- 一匹馬最多擁有1個個性
- 個性類型: 膽小、好勝、冷靜、暴躁、慢熱、喜歡領跑、不喜歡被包圍等。

## 名氣
- 隨著比賽獲勝增加，贏下越高層級的比賽或獲得年度獎項名氣增加越高。
- 達到一定名氣後成為明星馬，帶來更多贊助、周邊收入、種馬價值、比賽人氣等。

## 特性
- 一匹馬最多擁有2個特性
- 效果強度: 每個特性觸發時對所屬階段表現造成 ±5%~±8% 的修正(正面特性為加成、負面特性為懲罰)，實際數值依特性稀有度浮動；兩個特性同時觸發時效果分開計算，不額外疊加倍率。
- 特性類型:
    - 快速起步
        * 類型: 正面
        * 取得方式: 天生/訓練
        * 觸發條件: 起跑階段
        * 效果: 提升起跑表現
        * 是否可遺傳: 是
    - 彎道巧手
        * 類型: 正面
        * 取得方式: 天生/訓練
        * 觸發條件: 彎道階段
        * 效果: 提升彎道表現
        * 是否可遺傳: 是
    - 重馬場高手
        * 類型: 正面
        * 取得方式: 天生
        * 觸發條件: 重馬場
        * 效果: 提升重馬場表現
        * 是否可遺傳: 可能
    - 末段爆發
        * 類型: 正面
        * 取得方式: 天生/訓練
        * 觸發條件: 最後衝刺
        * 效果: 提升最後衝刺表現
        * 是否可遺傳: 是
    - 領放穩定
        * 類型: 正面
        * 取得方式: 訓練
        * 觸發條件: 起跑/前段 + 逃
        * 效果: 提升領跑表現
        * 是否可遺傳: 否
    - 抗壓
        * 類型: 正面
        * 取得方式: 訓練
        * 觸發條件: 大量觀眾、高層級賽事
        * 效果: 精神表現提升
        * 是否可遺傳: 否
    - 海外適應
        * 類型: 正面
        * 取得方式: 天生/訓練
        * 觸發條件: 海外賽事
        * 效果: 海外比賽表現提升
        * 是否可遺傳: 是
    - 容易緊張
        * 類型: 負面
        * 取得方式: 天生
        * 觸發條件: 大量觀眾、高層級賽事
        * 效果: 精神表現下降
        * 是否可遺傳: 可能
    - 慢熱
        * 類型: 負面
        * 取得方式: 天生
        * 觸發條件: 起跑/前段
        * 效果: 起跑/前段表現下降
        * 是否可遺傳: 可能
