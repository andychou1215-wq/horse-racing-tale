# 狀態與健康

定案: 「健康」是馬匹系統.md 列出的獨立屬性(0~100數值)，分級改用「無傷病風險/低傷病風險/中傷病風險/高傷病風險」四級，直接呈現受傷可能性；比賽公式.md 的「狀態倍率」則由「狀態(賽前分級)」決定，兩者是各自獨立的呈現。

## 健康(屬性)
- 對應 馬匹系統.md「詳細屬性」的健康，使用0~100數值，代表馬匹的長期身體底子，決定疲勞累積速度與受傷機率。
- 傷病風險分級: 由健康數值換算，分成「無傷病風險」「低傷病風險」「中傷病風險」「高傷病風險」四級，用於玩家介面呈現、交易估價(市場/馬匹市場.md)與傷病觸發機率判定，不直接參與比賽當天的表現計算。
- 長期比賽、高強度訓練會造成健康磨損，使健康數值下降、傷病風險分級隨之上升；可透過獸醫照護、休息與設施恢復。

## 狀態(賽前分級)
- 分級: S → A → B → C → D，由健康數值 + 目前疲勞值 + 精神屬性 + 賽前調整綜合決定，每次比賽前結算一次。
- 直接對應 比賽/比賽公式.md 的「狀態倍率」，由當下馬匹的狀態決定，是比賽當天實際影響表現的分級，與上方「傷病風險分級」是兩套獨立呈現(傷病風險分級偏長期體質，狀態分級偏賽前臨場)。

## 疲勞
疲勞會隨著訓練、比賽增加，可利用休息、放牧降低疲勞值

## 傷病風險
疲勞+健康+訓練強度+比賽頻率決定傷病風險分級(無/低/中/高)，分級越高、實際觸發下方「傷病」的機率越高。

## 傷病
- 嚴重度分級:
    - 輕傷
        * 恢復時間快
        * 不造成永久能力影響，但持續性的輕傷可能會提升傷病嚴重度
    - 中傷
        * 恢復時間一般
        * 根據受傷部位決定是否造成永久能力影響
    - 重傷
        * 恢復時間久
        * 會造成永久能力影響
        * 最嚴重者可會會導致馬匹立即退役

## 養傷
利用休息、放牧養傷恢復，也可聘請獸醫加速恢復速度。恢復健康時交由獸醫進行最終確認，獸醫最終確認可以放行後才能正常比賽。
