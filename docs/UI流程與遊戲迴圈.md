# 遊戲迴圈與UI流程

## 時間軸基礎
- 比照 賽事與生涯系統.md 的行事曆：一個賽事年度以週區分，每週拆成平日/假日。
- 季節性節點：配種期(4~6月，繁殖/血統與繁殖系統.md)、四場拍賣會(國際12月/精選1月/夏季7月/地方8月，市場/拍賣系統.md)、年度結算(每年底)。

## 主選單導覽結構
- 馬房：馬匹列表 → 點選進入個別馬匹詳細頁(屬性/潛力/特性/個性/生涯紀錄/健康)
- 訓練：本週訓練分配(逐匹馬選擇訓練/放牧/休息/醫療/模擬賽，或設定委託管理)
- 賽事：行事曆、報名、賽前準備(騎師/戰術/跑法選擇)、比賽結果
- 市場：現役馬/幼駒/種馬/繁殖母馬市場、拍賣會
- 繁殖：配種安排、幼駒管理
- 員工：訓練師/騎師/獸醫聘用與指定
- 設施：各項設施升級
- 財務：收支報表、負資產警示
- 馬主資料：聲望/事業等級、馬主聯盟排名、生涯總覽

## 每週核心迴圈
1. 週開始：系統結算上週事件(培育/隨機事件清單.md)、疲勞與傷病恢復進度，推播通知給玩家。
2. 平日(週一~週五)：為每匹馬分配當週訓練選項，或交由訓練師委託管理(重要馬匹仍可手動干預)。
3. 假日(週六/週日)：若有馬已取得參賽席位 → 進入「比賽日流程」；沒有比賽的馬可繼續培育或休息。
4. 週結束：結算疲勞、體力恢復、固定週支出(訓練費/馬房費等)，進入下一週。

### 委託管理UI切換
- 定案: 採「逐匹切換」，每匹馬在馬匹詳細頁/訓練分配頁上各自有獨立的委託管理開關，不設定全局(整個馬房一鍵切換)模式。
- 開啟委託管理的馬匹由訓練師依專長自動安排當週訓練，玩家仍可隨時手動覆蓋單一匹馬的當週選擇(對應 培育/訓練師系統.md「玩家也可手動干預重要馬匹」)。

## 比賽日流程
1. 賽前2週：完成報名、繳交報名費，系統依選拔規則決定正式參賽名單與候補順位。
2. 賽前1週：起跑檔位抽籤 → 騎師3輪配對(比賽模擬.md 已定案先後順序) → 玩家確認/調整戰術與跑法。
3. 比賽當日：結算賽前「狀態(S~D)」→ 比賽模擬(六階段位置值計算，比賽模擬.md) → 結果公布(名次/名次差距)。
4. 賽後結算：獎金分配(先扣人員分成)、聯盟積分、名氣變化、生涯紀錄更新、可能觸發年度獎項候補資格。

### 比賽呈現形式
- 定案: 採「純文字結算」，不做賽道動畫或視覺化模擬，開發成本較低。
- 結果頁至少呈現：六個階段(起跑/前段/中段/後段/彎道/衝刺)的即時位置值變化、最終名次、關鍵轉折的文字敘述(例如「衝刺階段OO馬反超」)，讓玩家仍能感受到比賽過程的起伏，而非只看到最終名次。

## 月度/季節性流程
- 每月：市場買賣馬匹、員工調整(聘用/解約)。
- 配種季(4~6月)：安排繁殖馬配種、獸醫配種前後檢查。
- 拍賣會月份：依拍賣會種類參與競標(需先完成資金驗證)。

## 年度結算流程
1. 賽季結束：聯盟積分結算 → 升降級(最高級2升2降，其餘3升3降)。
2. 年度獎項評選與頒發(年度獎項.md)。
3. 馬匹考慮退役(依成長階段建議、玩家最終決定) → 進入繁殖/展示/養老。
4. 設施投資規劃，NPC馬主同步進行「年度結束」決策(退役/出售/設施投資)。
5. 新賽季開始，行事曆重置、聯盟積分歸零。

## 通知與待辦事項
- 定案: 採「清單模式」，列出玩家尚未進行的事務，不做彈出式強制提醒。
- 待辦清單集中呈現於主選單(例如「待辦」入口或首頁角標)，項目包含但不限於：
    * 本週尚未安排訓練的馬匹
    * 已取得候補/正式資格但尚未確認騎師的比賽
    * 賽前1週尚未完成的起跑檔位抽籤/騎師配對
    * 傷病已痊癒待獸醫最終確認放行的馬匹
    * 資金即將轉負、財務系統示警
    * 拍賣會/配種季開放中但尚未行動
- 每個待辦項目可直接點擊跳轉至對應處理畫面；已處理或已過期的項目自動從清單移除。
