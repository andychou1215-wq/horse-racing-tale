# 員工系統

## 騎師系統
- 不同騎師有不同能力能讓「馬 × 騎師」形成組合策略。
- 玩家可由騎師市場聘用專業騎師或是從騎師學校畢業名單與新人騎師簽約並讓新人騎師與馬匹一同成長。
- 玩家在報名馬匹時不需要指定騎師。只有選拔完成並正式取得參賽席位的馬匹，才需要安排騎師。
- 同一名騎師在同一週可以參加多場賽事，不設定單週固定場數上限；但一旦確定在某座賽馬場出賽，該週的其他騎乘也必須位於同一座賽馬場。
    - 只要遵守該規則，該騎師便可以在該賽馬場持續參加多場比賽。
    - 同一名騎師在同一週、同一賽馬場、不同場次可以接受多個邀約，只要符合排程規則並承擔相應疲勞。

### 騎師市場
- 馬主不需要只依靠自己長期簽約的騎師。正式取得參賽席位後，可以在比賽前一週從符合條件且檔期可用的自由騎師中安排騎乘。
- 自由騎師的配對與決策邏輯詳見 比賽/騎師AI.md。

## 獸醫
- 獸醫可進行以下項目:
    * 傷病診斷
    * 恢復效率
    * 傷病預防
    * 健康評估精度
    * 配種前後檢查
- 一個獸醫最佳照顧5隻馬匹，照顧6～8匹時治療效率下降，並無法照顧9匹以上。
