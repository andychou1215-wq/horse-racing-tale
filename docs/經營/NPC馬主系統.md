# NPC馬主系統

## NPC馬主
- NPC馬主必須能：
    * 買馬
    * 賣馬
    * 繁殖
    * 培育
    * 報名賽事
    * 挑選騎師
    * 安排賽程
    * 淘汰弱馬
    * 培養強馬
    * 維持財務
    * 發展設施
- 可以讓不同 NPC 有經營人格：
    * 血統派 → 傾向依賴血統決定馬匹價值
    * 高價買馬派 → 願意將大部分資金投入明星馬
    * 自家育成派 → 優先升級育馬場與繁殖馬
    * 短距離專精 → 優先培養短距離適性馬
    * GI 專攻 → 將馬匹培養成專門為GI賽事準備
    * 大量出賽型 → 更重視健康、恢復與大量中級馬
    * 菁英少馬型 → 馬房只維持少量高潛力馬
- 低階聯盟 → 平均較弱馬主，高階聯盟 → 本來就存在強大馬主
- NPC馬主名字採隨機生成

## 決策週期
- 每週: 訓練、休息、報名
- 每月: 買賣馬匹、員工調整
- 繁殖季: 繁殖決策
- 年度結束: 退役、出售、設施投資

## 決策邏輯
- 修正說明: 原本只定義NPC馬主「必須能做什麼」與7種人格標籤，沒有具體的決策邏輯，現補上以評分制為核心的通用框架。

### 通用框架
- 各項決策(買馬/賣馬/訓練分配/報名/騎師挑選)皆採「評分制」：對每個候選選項套用該NPC人格的加權公式算出分數，選擇分數最高的選項執行；最高分低於人格設定的行動門檻時，該週不採取行動。
- 每次決策前先檢查財務系統.md 的負資產限制：資金低於安全庫存(約當4週固定支出)時，全部權重轉向「維持財務」，暫停買馬與高級員工聘用等非必要支出。

### 買馬決策
- 評分 = 血統權重×血統分數 + 能力權重×已知能力分數 + 潛力權重×潛力評估分數(鑑定不完全時以期望值計算) − 價格權重×市場開價。
- 人格權重差異(節錄):
    * 血統派：血統權重最高，價格權重低(願意為血統溢價)。
    * 高價買馬派：能力/潛力權重最高，鎖定拍賣會估價前段班的明星馬，價格權重低。
    * 自家育成派：買馬評分整體偏低，資金優先投入育馬場/繁殖母馬。
    * 短距離專精：短距離適性S/A的馬額外加分。
    * GI 專攻：整體潛力評估A以上的馬額外加分。
    * 大量出賽型：健康分級高、價格中等的馬額外加分(避免買貴又帶傷的馬)。
    * 菁英少馬型：馬房未滿少量上限(例如3匹)且候選馬評分超過高門檻時才出手。

### 賣馬/淘汰決策
- 每月結算時，對馬房內每匹馬計算保留分數 = 目前能力表現 + 潛力剩餘成長空間 − 維護成本負擔，低於門檻者列入待售/淘汰候選。
- 菁英少馬型、GI專攻的保留門檻設得較高(積極汰弱留強)；大量出賽型門檻較低(容忍更多中級馬)。

### 訓練分配決策
- 依人格對11項屬性各自設定訓練權重表(例如短距離專精集中在速度/加速/起跑；GI專攻權重平均分配追求綜合能力)，每週優先訓練權重最高且尚未逼近潛力上限的屬性。
- 等同於馬房內所有馬匹都開啟 培育系統.md 的委託管理，由訓練師依此權重表自動安排。

### 報名決策
- 優先選擇馬匹評級落在該賽事目標名次範圍內的賽事，避免以卵擊石或殺雞用牛刀；依人格調整偏好(GI專攻優先國際賽事、短距離專精優先短距離賽事、大量出賽型偏好參賽門檻低的地方賽以拉高出賽頻率)。
- 馬匹疲勞偏高或傷病風險偏高時，報名意願下修，優先安排休息。

### 騎師挑選決策
- 在預算上限內，選擇「騎師適配度+騎師修正」加權分數最高的可用自由騎師(比賽/騎師AI.md)；高價買馬派、GI專攻願意支付更高比例預算聘用明星騎師，大量出賽型偏好中價位、檔期彈性高的騎師。

## 破產與遞補
- 修正說明: 財務系統.md 的破產機制原本只針對玩家馬主，NPC馬主是否會破產、破產後如何處理未定義，現補上。
- NPC馬主適用與玩家相同的破產判定(負資產達一定金額)，破產後該NPC馬主永久離開模擬世界，旗下馬匹依比例分配至市場拍賣、其他NPC馬主收編、或直接退役。
- 每個賽事年度結束時，系統依當前NPC馬主總數與 世界模擬.md 的馬匹人口數字，隨機生成新NPC馬主遞補破產或退出的名額，維持聯盟與市場的馬主數量穩定。
