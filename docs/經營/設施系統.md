# 設施系統
馬主設施將會有馬房、各項屬性的訓練場、恢復中心、醫療中心、育馬場等。

## 馬房
- 放置馬匹。
- 等級與容量:
    * Lv1 → 10匹
    * Lv2 → 20匹
    * Lv3 → 30匹
    * Lv4 → 40匹
    * Lv5 → 50匹

## 速度訓練場
- 提升速度與加速成長。
- 等級與效果:
    * Lv1 → 無
    * Lv2 → 訓練效率提升
    * Lv3 → 訓練效率提升
    * Lv4 → 訓練效率提升
