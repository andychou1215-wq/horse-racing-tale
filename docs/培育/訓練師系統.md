# 訓練師系統

## 訓練師專長
- 不同訓練師的專長會影響訓練效果。
- 訓練師專長種類:
    * 速度訓練能力
    * 耐力訓練能力
    * 幼駒培育
    * 狀態管理
    * 傷病預防
    * 戰術能力
    * 潛力評估
        * 評估能力影響資訊精度，而不是改變馬匹本身。

## 訓練師聘用
- 玩家可由訓練師市場聘用訓練師來訓練馬匹。
- 一個馬匹最多指定一個訓練師，但一個訓練師可以訓練多隻馬匹。
    - 一個訓練師最佳管理8隻馬匹，管理9～12匹時訓練效率下降，並無法管理13匹以上。

## 委託管理
- 玩家可以負責高層決策，並將日常工作交給訓練師負責自動安排訓練。
- 玩家也可手動干預重要馬匹。
