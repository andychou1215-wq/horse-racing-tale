# 隨機事件清單

## 事件機制
- 同一對象4週內不重複觸發相同事件。
- 部分事件觸發時會提供玩家選擇，其餘為直接結算的被動事件。

## 觸發機率
- 修正說明: 原本只有事件內容，沒有觸發機率的數值設計，現補上。
- 每個對象(馬匹/騎師/訓練師/馬主)每週各自獨立判定一次基礎觸發機率5%，判定通過後才從對應清單抽出一個具體事件。
- 正負面抽取比例固定 45:55(正面較少，維持一定的風險感，NPC與玩家共用同一套機率，不特別優待)。
- 稀有度分兩級，決定抽中機率的權重：
    * 一般(權重3): 除下方列出的「罕見」外，其餘事件皆屬一般。
    * 罕見(權重1，效果通常較強或永久性): 馬匹「潛力覺醒」「突破成長」「特性覺醒」，騎師「技術突破」，訓練師「業界推薦」，馬主「投資機會」。
- 額外修正:
    * 該對象本週有安排比賽或模擬賽時，觸發機率額外 +3%(高強度活動更容易誘發意外，正負面事件都適用)。
    * 馬匹健康分級為「無傷病風險」或「低傷病風險」時，負面事件抽取比例下修5%(45:55 → 50:50)；「高傷病風險」時負面比例上修5%(45:55 → 40:60)，呼應健康屬性的存在意義。

## 馬匹事件

### 正面
- 潛力覺醒
    * 對象: 馬匹
    * 效果: 潛力值小幅提升，且提升部份不受近親繁殖懲罰影響
- 突破成長
    * 對象: 馬匹
    * 效果: 隨機一項屬性額外獲得一次訓練份量的成長，不消耗當週訓練選項
- 特性覺醒
    * 對象: 馬匹
    * 效果: 若特性數未滿上限(2個)，隨機取得一個「天生/訓練」類特性
- 伯樂發現
    * 對象: 馬匹
    * 效果: 觸發一次免費的「專業評估」，潛力資訊精確度提升一級
- 人氣飆升
    * 對象: 馬匹
    * 效果: 名氣值提升，短期內周邊/贊助收入增加
- 幸運訓練
    * 對象: 馬匹
    * 效果: 當週訓練效果加倍，不影響疲勞累積
- 良好適應
    * 對象: 馬匹
    * 效果: 隨機一項場地/距離適性提升一級

### 負面
- 輕微擦傷
    * 對象: 馬匹
    * 效果: 觸發「輕傷」等級的傷病，需要短期休養
- 疲勞加劇
    * 對象: 馬匹
    * 效果: 疲勞值大幅上升，本週訓練效果打折
- 心理受挫
    * 對象: 馬匹
    * 效果: 精神屬性短期下降，容易在下一場比賽發生失常
- 鬧脾氣
    * 對象: 馬匹
    * 效果: 依馬匹個性觸發拒絕本週指定訓練，訓練師需額外時間安撫
- 意外生病
    * 對象: 馬匹
    * 效果: 健康分級下降一級，需要獸醫介入治療
- 適應不良
    * 對象: 馬匹
    * 效果: 隨機一項場地/距離適性下降一級
- 負面緋聞
    * 對象: 馬匹
    * 效果: 名氣小幅下降，短期贊助收入減少

## 騎師事件

### 正面
- 狀態絕佳
    * 對象: 騎師
    * 效果: 下一場比賽騎乘表現獲得短期加成
- 技術突破
    * 對象: 騎師
    * 效果: 騎師能力小幅永久提升
- 意外邀約
    * 對象: 騎師
    * 效果: 收到其他馬主的挖角邀約，玩家可選擇加碼留人或放任(若放任則該騎師檔期可能被優先預約排開)
- 媒體關注
    * 對象: 騎師
    * 效果: 騎師知名度提升，帶動所屬馬匹的人氣加成

### 負面
- 賽場受傷
    * 對象: 騎師
    * 效果: 騎師需要短期休養，該段時間內無法安排騎乘
- 體重管理失敗
    * 對象: 騎師
    * 效果: 短期內配重負擔增加，對應比賽表現略為下降
- 士氣低落
    * 對象: 騎師
    * 效果: 短期內騎乘表現下降
- 負面新聞
    * 對象: 騎師
    * 效果: 騎師聲望下降，可能影響自由騎師市場的邀約競爭力

---

## 訓練師事件

### 正面
- 訓練師進修
    * 對象: 訓練師
    * 效果: 隨機一項訓練師專長能力提升
- 意外洞察
    * 對象: 訓練師
    * 效果: 潛力評估專長暫時提升一級，本週內鑑定的馬匹可取得更精確資訊
- 業界推薦
    * 對象: 訓練師
    * 效果: 訓練師聲望提升，帶動旗下馬匹訓練效率小幅加成

### 負面
- 過度勞累
    * 對象: 訓練師
    * 效果: 短期內管理效率下降，等同於超出最佳管理匹數的效果
- 離職風波
    * 對象: 訓練師
    * 效果: 玩家需支付額外費用挽留，否則訓練師離開並解除所有指定馬匹
- 訓練事故
    * 對象: 訓練師
    * 效果: 該訓練師當週指定的馬匹之一意外增加受傷風險

## 馬主事件

### 正面
- 貴人相助
    * 對象: 馬主
    * 效果: 獲得一筆額外資金或聲望
- 媒體採訪
    * 對象: 馬主
    * 效果: 馬主聲望提升，加快事業成長等級累積速度
- 贊助商上門
    * 對象: 馬主
    * 效果: 獲得短期贊助收入加成
- 投資機會
    * 對象: 馬主
    * 效果: 玩家可選擇投入資金換取未來收益，也可放棄

### 負面
- 設施故障
    * 對象: 馬主
    * 效果: 隨機一項設施本週效果失效，需支付維修費恢復
- 稅務稽查
    * 對象: 馬主
    * 效果: 扣除一筆資金
- 負面新聞
    * 對象: 馬主
    * 效果: 馬主聲望短期下降
- 天災意外
    * 對象: 馬主
    * 效果: 馬房內隨機一匹馬健康分級下降一級，需獸醫介入
