# 拍賣系統

## 拍賣會規則
- 要拍賣的馬須通過拍賣會委員會審核後才能進行拍賣。
- 競標底價由拍賣會委員會估價決定。
- 競標者必須註冊並驗證資金後方可出價。
- 競標流程：價格逐級遞增，直到電子計時器結束，最高出價者贏得該馬匹。
- 馬主搶標時不得標出比自身資產還高的金額。
- 買家得標後需立即處理付款。

## 拍賣會種類
- 國際拍賣會
    - 舉辦時間: 每年12月
    - 拍賣馬種類: 知名國際種馬 + 知名國際種馬幼駒
    - 競標金額: 超高
- 精選拍賣會
    - 舉辦時間: 每年1月
    - 拍賣馬種類: 知名種馬 + 知名種馬幼駒
    - 競標金額: 高
- 夏季拍賣會
    - 舉辦時間: 每年7月
    - 拍賣馬種類: 高能力/潛力現役馬
    - 競標金額: 中
- 地方拍賣會
    - 舉辦時間: 每年8月
    - 拍賣馬種類: 幼駒 + 現役馬 + 種馬 + 繁殖母馬
    - 競標金額: 低
